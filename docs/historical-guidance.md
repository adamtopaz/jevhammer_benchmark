# Guidance ablations before the public repositories

The original monolithic experiments **did include Jev/no-Jev ablations**. These
were missing from the stable repositories' reports. It would be incorrect to
describe the entire research history as having no evidence for model guidance.

The largest archived matched comparison used 1,024 intermediate locations from
429 declarations in 31 Mathlib modules, with a six-second end-to-end deadline:

| Old monolithic method | On-time solves | Raw successful proofs |
|---|---:|---:|
| Neural premise retrieval + Jev ordering | 459 (44.8%) | 462 |
| Same engine and neural retrieval, no Jev ranker | 400 (39.1%) | 400 |

Jev gained 88 locations and lost 29: **+5.76 percentage points**. The archived
declaration-cluster bootstrap interval was **[3.18, 8.29] points**, conditional on
that fixed module sample. All 4,096 trials across the original four arms were
recorded without censoring. The archived replay record covers all 1,604 raw
successes across those arms. This audit rereads evidence; it does not rerun Lean.

## What was changed

The frozen [backend](historical-guidance/JevHammerBackend.lean) passes identical
adaptive-search limits and the same neural retrieval callback to both arms.
The [harness](historical-guidance/AtEachStep.lean) passes a ranker only to the
`neural_search_jev` arm. In the frozen [engine](historical-guidance/Advanced.lean),
that ranker orders **both premises and successor proof states**. Without it,
candidate order is retained and ranking calls are not counted. Call counts also
gate premise refresh. This is a combined-guidance comparison, not an isolated
proof-state ablation with matched ranking slots.

The guided arm made 2,010 fresh requests and used 52 cached decisions; recorded
cache latency was charged. The selected method and evaluation cohort were frozen
after development. Neural-selector and Jev pretraining overlap remains unknown.
This older sample, engine, and historical resource configuration differ from
the current published system; do not pool its scores with the modern studies.

An earlier, separate Lean 4.34 experiment (`finish-confirm-v2`) also reported
164/256 for independent Jev premise/state scoring, 157/256 for Jev Choice, and
141/256 for the unguided hybrid. It is background evidence from the old notes;
the public row-level audit below is for the larger Lean 4.33 comparison only.
No random-order comparison was located in those archived reports.

## Check the recovered evidence

[Sanitized trial metadata](historical-guidance/trials.jsonl) contains all 2,048
rows for the two relevant arms. The [audit](historical-guidance/audit.json)
records checksums of the original raw trials, manifest, protocol, replay record,
and source snapshots. The copied Lean files are historical evidence, not build
targets or implementations of the current tactic.

```sh
python3 scripts/audit_historical_guidance.py
```

This checks public hashes and recomputes coverage, pairing, and request counts.
The interval and replay record are explicitly preserved historical results,
not independently regenerated by this metadata checker. The export can also be
regenerated with `--archive PATH/TO/final-practical-v1 --export` if the original
archive is available. It never launches historical proof commands.

The new [current-system ablation](guidance-ablation-protocol.md) keeps premise
selection fixed and compares Jev, fixed, and seeded-random **state** ordering.
